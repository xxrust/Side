Important fixes
  Dragging invalidates displayed candidates and measurements immediately;
  releasing recomputes and displays feedback. A dedicated ROI handle distinguishes
  movement from clicking a candidate. Original intent strokes are collapsed.
  Candidate single-select replaces the old selection; multiple selection is explicit.
  One prominent task action commits the current form rather than reopening it.
  Selected tools retain task focus; other unconverted intentions do not hijack it.
  Frame goal maps the user's four intentions to explicit top/bottom/left/right roles.
  Four dependencies are captured by recipes. Missing/stale/ambiguous/reversed/
  degenerate geometry fails closed. Every measurement requires its own tolerance.
  Line support span requires explicit acknowledgment and is never the default.
  Algorithm demo-0.7 removes only evidenced isolated scan spikes and permits
  tightly bounded sparse two-scan gaps. All original residual, coverage, local
  support and persistent jump checks remain. These gates are heuristics, not
  mathematical guarantees about arbitrary images.
  profileWidth (odd 1..15; default 1) performs tangential profile averaging.
  ROI and masks cover the entire sampling kernel. The two vertical ROIs use
  y=260..680 and profileWidth=15; the horizontal searches use profileWidth=1.
