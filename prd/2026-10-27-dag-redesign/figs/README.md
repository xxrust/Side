# AgentCV PRD 示意图

专业产品文档风格 HTML/SVG 示意，可嵌入 PRD；同目录附 PNG 导出。

| 文件 | PRD 章节用途 |
|------|-------------|
| `fig1-dependency-dag.html` / `.png` | **默认依赖图 UI**：`requires` 实线硬前提、`shares` 虚线扇出 + 共享徽标/版本；Agent 推导边 vs 人否决；线性步骤条废案反例；`blocked_by` 沿边传递。 |
| `fig2-node-workspace.html` / `.png` | **节点工作区**：同板 ≥2 检测图 + PDF；共享定位一份可编辑 ROI + 下游只读幽灵叠层；原位问题气泡与测距钉边；验收「全程不打开右侧对话」。 |

## 视觉语言（已锁）

- `requires`：蓝色实线箭头（产出 → 消费）
- `shares`：青色虚线扇出；共享节点带「共享」徽标 + 版本号
- 废案：红色「废」标注的线性 1 › 2 › 3 步骤条
- 正文色 `#111`；面板浅灰；截图不看标签也应能分实线前提 vs 虚线扇出
