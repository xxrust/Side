## 改动与所有权

`buildProgramFlow` 新增默认关闭的 `shareImmutableFacts` 选项。流程显示和
`programScope` 只读路径开启该选项，使用 `projectSnapshot` 共享已经过 JSON
归一化、递归冻结且由模块私有 WeakSet 认证的结果、程序追踪和 JSON 产物子树。
图结构、图节点、产物描述符和其他可变元数据仍分别复制。任意用户对象或仅
`Object.freeze` 根对象均不能取得共享资格。

默认 `buildProgramFlow` 继续返回独立可编辑的事实副本。项目编辑、解说修订、
输入/输出图加载、撤销/重做与存储流程没有迁移到显示模型；显示路径不取得
修改执行事实的权限。共享对象在项目所有权之外不会另建全局缓存。
