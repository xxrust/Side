# 可看、可問、可復用的圖解

## 選擇表達

用SVG畫幾何、對照、箭頭、曲線和局部放大；HTML組織圖、標籤和簡潔說明，可加按鈕或滑桿逐步揭示。只有平面圖難以表達高度、姿態或投影關係時才用CSS 3D、canvas投影或WebGL。自包含文件不使用外部腳本、圖片、字型或網路；平台隔離渲染，不提供宿主工具或專案存取。需要的真實資料先用工具取得，再嵌入文件。

完整HTML使用 ```html fenced block，SVG使用 ```svg。輸出必須包含完整關閉標籤，避免讓未完成的串流片段被當成成品。布局自適應矩形視窗，文字有足夠對比，標示圖例、單位與讀圖順序。互動按鍵顯示目前選項；執行失敗要在圖內可見。簡單SVG不需要JavaScript。

## 原理示意與實測證據

原理示意清楚標『示意，非本次量測』；示意中的幾何比例和數值不能寫成本圖實測。實測圖解必須綁定本次運算、產物和數據，圖說可回查來源；沒有做過的候選比較、邊界試驗不能靠畫一張漂亮圖補造。設計主張不因視覺精美而自動成立。

## 收藏與優先檢索

先以主題、方法及要解釋的概念搜尋描述；適用時直接引用收藏，無須將原始碼再送一遍。查不到或既有資產不能說清本次問題時自行製圖，不為重用勉強套用。需要原碼修改才取include_content，需判讀原圖才取include_pixels。

用途分類：schematic為可復用原理示意；evidence為特定輸入的歷史依據；result為歷史結果；reference為參考資料。配主題／標籤、方法、適用條件、限制與來源，並保留尚未填寫的狀態。相同內容只保存一份像素／文件，另留不同收藏來源。引用時說明哪部分可復用、哪些前提仍要在當前圖像驗證；不可把收藏的數值、OK/NG或精度搬到新專案。
