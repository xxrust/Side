每次 CV 工具調用，都有相同的可核對入口

這是工具共用的資料契約與檢視器，不是每個工具各寫一份說明頁。前景五步和方案五步已接入；新增 CV 工具必須註冊角色並提供圖像渲染器，單純文字報告會被拒絕。

契約欄位要求
binding / status輸入圖 ID／SHA-256、當次 run、方案 ID／版本、對象、檢查項及選定邊；正在計算或失效時，不能把舊輸出當當前證據。
figures至少一個圖像入口：原圖、疊合、中間結果、統計或實際試探紀錄。未計算時顯示輸入與狀態；缺少的資料不補造。實算、記錄重建、選擇示意與教學反例標明來源。
choice任務、此工具的必要作用、可觀察輸出、假設和選擇來源。內建流程不聲稱由 Agent 比較所有算法後選出最佳者。
parameters逐參數包含 ID、值、單位、來源、原因、對應圖及邊界。來源區分工程預設、人工確認、規則推導、逐組試探、計算輸出；舊值缺來源則如實標示。
metrics / limits圖下展示實際數值與門檻，深層限制可展開。通過工程門檻不等於正確概率，也不等於尺寸誤差或任意噪聲下穩定性的證明。

同一套資料，同時供人和 Agent 使用

檢視器以圖為主，數字其次，文字保留在深入詳情。引用圖像時保存當時的圖表事實、參數來源和版本，生成可修改的對話草稿；不自動調用模型，也不自動傳整張圖或大型像素陣列。附圖仍由使用者決定。

project1 的實例

每邊完整比較 1／5／9／15 px × 中段 60%／50% 八組，第一組通過後仍繼續。上、下邊各八組通過，右邊四組通過，左邊只有 15 px／中段 50% 通過。單組通過只代表可用，不提供跨參數一致性證據。各組有歧義或共同支持跨度內的線位差大於 3 px 時保留 UNKNOWN；3 px 沿用本版候選歧義的工程尺度，不是校準精度。其餘優先較窄平均、同寬優先較長搜尋段；較低 RMS 不等於最佳精度。閾值 18 是舊方案保存值；灰階剖面可以核對它如何起作用，不能反過來聲稱它是由該曲線計算的最優值。
